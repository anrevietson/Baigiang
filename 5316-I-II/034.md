# Sayings on money

Gospel (Lk 16:9-15). Today's gospel contains a number of sayings connected to each other by the link word mammon, an Aramaic word which means 'wealth, property or money'. The overall gospel caution about the ensnaring character of money runs through each of these sayings. To be able to use money wisely, that is for the benefit of people, is like walking a tightrope. It is so easy to get pulled off balance.
