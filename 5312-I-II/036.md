# We need each other

First Reading (Rom 12:5-16). We need each other; we depend on each other. That's why we need to encourage each other 'to apply our various gifts for the good of the whole community. We must not give up such mutual encouragement even if trials come, even if the effort at co-operation seems to have little success.
